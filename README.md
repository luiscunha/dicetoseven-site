# DiceToSeven — o site

As páginas públicas do jogo, publicadas no GitHub Pages:

| Página | Para quê |
|---|---|
| `index.html` | Apresentação, e mais tarde os links das lojas |
| `privacy.html` | A política de privacidade — o link que as duas lojas pedem |
| `support.html` | O suporte — o link que a App Store pede |

Cada página tem o texto nos quatro idiomas do jogo, e mostra o da língua do
dispositivo (inglês quando não é nenhum deles). `?lang=pt`, `en`, `es` ou `fr`
no endereço escolhe um à mão; é o que os botões do topo fazem.

**O jogo não está aqui.** O código vive num repositório privado; este só tem
HTML, CSS, o ícone e a fonte do nome (Fredoka, SIL Open Font License 1.1).

## Publicar

*Settings → Pages → Build and deployment → Deploy from a branch → `main` /
`(root)`.* Cada push para a `main` atualiza o site em um ou dois minutos.
